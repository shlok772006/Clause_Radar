# 10 — Build Plan

Five days, solo, agent-assisted. Tasks are sized for one agent run each. Feed them one at a time. Commit after every green task.

**Rule:** if a day's "must ship" is not done by the end of that day, cut from the bottom of the cut list in `01-PRD.md` — do not push work forward.

---

## Day 1 — The spine

**Must ship:** a PDF uploads, becomes clauses, renders in the left pane, and clicking a clause ID highlights it on the correct page.

| # | Task | Definition of done |
|---|---|---|
| 1.1 | Scaffold Next.js 15 + TS strict + Tailwind + Vitest. Add `AGENTS.md`, `docs/`, `config/`. Design tokens from `09-DESIGN-DIRECTION.md` in `globals.css`. | `npm run dev` serves a styled page; `npm run test` runs |
| 1.2 | `lib/types.ts` verbatim from `03-DATA-CONTRACTS.md` | Compiles, nothing else references undeclared fields |
| 1.3 | `lib/pdf.ts` — pdfjs text extraction with a page-offset map | Given a fixture, returns full text plus correct `pageBreaks` |
| 1.4 | `lib/segment.ts` + `lib/segment.test.ts` — text → `Clause[]` | 8+ passing assertions; produces sane clauses on all three fixtures |
| 1.5 | **`components/DocumentPane.tsx`** — pdfjs viewer with text layer, plus `highlightClause(clauseId)` via anchor matching | Calling it from the console scrolls and highlights correctly on page 1, a middle page, and the last page. **Fallback to page-level highlight when the anchor is not found.** |
| 1.6 | `/api/ingest` + `lib/store.ts` with TTL sweeper; upload UI with validation | Upload a fixture → get a `sessionId` → land on `/review/[id]` with the document rendered and clauses listed |

**1.5 is the riskiest task in the entire build.** If it is not working by the end of Day 1, stop everything and fix it — the whole product claim rests on it. If it is still broken after four hours, fall back to citing page numbers with a page-level tint and move on; do not lose a day.

## Triage, if you fall behind

Cut in this exact order. Each line is a full feature you can lose without damaging the core claim:

1. Text-to-speech
2. Translation
3. PDF report export
4. Plain-language rewrite toggle
5. Negotiation email (keep the lawyer-questions list — it is cheaper and more on-mission)
6. Concern ranking (keep the picker, use a fixed order)

**Never cut:** the verifier, the refusal path, the missing-clause engine, click-to-highlight, or the eval harness. Those five *are* the project.
